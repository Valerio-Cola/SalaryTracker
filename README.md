# 📊 Work & Salary Tracker

## 💡 Il Progetto: Cos'è e perché è nato

**Work & Salary Tracker** è un'applicazione web personale pensata per semplificare la gestione della propria vita lavorativa e finanziaria. L'app funge da dashboard dove è possibile registrare i propri turni di lavoro, calcolare in automatico lo stipendio stimato in base alle ore svolte e tracciare le spese quotidiane. Attraverso un'interfaccia chiara e grafici intuitivi, permette di avere sempre sotto controllo il proprio bilancio mensile netto entrate vs uscite.

L'idea è nata da una duplice esigenza:
1. **Uno strumento su misura:** Avere a disposizione un tool personalizzato per la mia compagna, essenziale e focalizzato sulle proprie necessità, senza dover dipendere da app commerciali complesse o a pagamento.
2. **Esplorazione tecnologica:** Questo progetto è stato realizzato interamente tramite **Google AI Studio** come esperimento pratico. L'obiettivo era testare sul campo le enormi potenzialità dello sviluppo software assistito dall'Intelligenza Artificiale, studiando e integrando tecnologie web moderne e performanti.

## ✨ Funzionalità Principali

- **📅 Gestione Turni:** Inserimento e monitoraggio dei turni lavorativi con calcolo automatico dei compensi.
- **💸 Tracciamento Spese:** Registrazione delle spese per avere un bilancio chiaro a fine mese.
- **📈 Dashboard e Grafici:** Visualizzazione dei dati tramite grafici interattivi per analizzare l'andamento delle finanze.
- **☁️ Sincronizzazione Cloud:** Salvataggio e sincronizzazione dei dati multi-dispositivo supportato da Cloudflare Workers solo per utenti autorizzati.
- **🛡️ Sicurezza Avanzata:** Integrazione nativa con **Cloudflare Turnstile** per la protezione anti-bot in fase di accesso.
- **📱 Design Responsivo:** Interfaccia utente moderna e adattabile a qualsiasi dispositivo.

## 🛠️ Stack Tecnologico

- **Frontend:** React 18 (Hooks, Functional Components)
- **Build Tool:** Vite
- **Linguaggio:** TypeScript per una maggiore solidità e type-safety
- **Styling:** Tailwind CSS per un design moderno e pulito
- **Backend/Sync:** Cloudflare Workers (Edge Computing)
- **Sicurezza:** Cloudflare Turnstile
